# 与行程衔接块

每份深度讲解在六段正文之后，**必须**追加一节「行程衔接」（可用该小标题）。供 travel-planner 或其他排程直接摘录；不在此节重讲历史。

## 固定字段

按下列条目输出，缺信息则标「公开资料暂列／未核实」，不要留空不说明：

1. **建议停留时长**：给出至少两档（例如 20 分钟速览／45–60 分钟细看），并各用一句话说明能覆盖到哪一步观察。
2. **体力档**：低／中／高，并注明主要消耗（楼梯、步行距离、站立观展、室外风晒等）。
3. **与相邻点的空间关系**：相对已知锚点（酒店、车站、上一景点、下一餐）的方位与大致距离或步行／车行分钟数；无锚点时写「待排程填入相邻点」。距离与交通须标注查阅日期与来源层级。
4. **雨天／闭馆／高峰备选**：至少一条可执行备选（室内点、缩短动线、改期窗口或邻近同主题建筑）；说明触发条件（若X则Y）。
5. **预约与门禁提醒**（若相关）：是否通常要预约、证件、行李限制；动态规则标「出发前再核」。

## 写法约束

- 短句条目，避免散文；不要在此节展开风格史。
- 不替代 travel-planner 的门到门排程与预算；只提供可被引用的约束与弹性。
- 不在此节承诺代订或付款。
- 若本次只是桌面研究、不到现场：停留与体力改为「图面／影像阅读时长」，并标明「未到现场」。

## 示例骨架（占位须替换为核实后内容）

```text
### 行程衔接
- 停留：20 分钟可看清主立面与门厅结构；60 分钟可走完主路径并看 3 处细部（公开资料暂列）
- 体力：中（多层楼梯／室外石板路）
- 相邻：相对××酒店步行约 N 分钟（查阅日期：YYYY-MM-DD）
- 若下雨或闭馆：改去××（室内）或压缩为只看外立面
- 门禁：是否预约／行李——出发前再核官网
```
