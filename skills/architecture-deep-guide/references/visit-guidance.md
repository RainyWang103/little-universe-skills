# 参观动线与观察

## 动线原则

1. **先整体后局部**：立面或总平面关系 → 进入序列 → 主空间结构逻辑 → 细部与材料 → 外围／后院／屋顶（若开放）。
2. **结构可读处优先**：能看清承重与传力的位置，优于仅作打卡的装饰面。
3. **光与使用**：自然光口、人工照明、现在的使用方式如何改写原设计意图。

## 时间档

| 档位 | 建议内容 |
|------|----------|
| 约 20 分钟 | 定位句 + 主立面／主厅结构一眼看懂 + 1–2 个细部 |
| 约 45–60 分钟 | 完整六段中的现场可观察部分，按动线走完主路径 |
| 90 分钟以上 | 加专题（材料样本、铭文、改建层位、与城市轴线关系） |

现场封闭或部分封闭时，改为图面／街景／出版物插图的观察顺序，并标明「未到现场」。

## 观察清单模板

对每个建议停留点写清：

- 站位点（如「中殿中央向西望」）
- 看什么（构件／空间／材料）
- 读什么（结构逻辑或历史信息）
- 常见误读（可选）

## 实用信息

开放时间、票价、预约、交通、无障碍以查阅当日公开信息为准，标注「公开资料暂列」与查阅日期；动态规则变化快，不写死为「永远如此」。
