# 下半部插图生成模板

以所附原照片为唯一内容参考，生成一个 3:2 横向纸本插图分区。
只生成海报下半部，不生成照片分区、拼贴、外框或文字。

照片内容：{{主体、姿态、重要物体与核心叙事关系}}
必须保留：{{立即辨识所需的关键特征}}
主要颜色（最多四种）：{{从照片提取的颜色}}

将照片高度简化为精致的手绘纸本封面插图。保留基本轮廓与比例、关键姿势，
以及人物和物体之间的关系。删除不必要的细节与复杂背景，不新增主体或重要物体。

使用细腻、略带瑕疵的手绘线条，少量大胆但受控的丙烯风格平面色块，
可见而克制的手工笔触及略微不规则的有机边缘。
背景为温暖米白的粗糙自然纸张，纸张颗粒细腻，不使用强烈污渍或夸张做旧。
仅以少数线条或小色块暗示环境。

主插图组合小巧居中，紧凑外接框面积约占整个分区的 10–20%；四周大量留白。
色彩直接回应原照片，最多四种主要插图颜色，纸底色除外。
整体呈现安静、克制的高端艺术出版物封面质感。

避免摄影质感插画、3D、光滑矢量质感、渐变、复杂阴影、装饰图案、文字、水印。

# 上半部背景扩展模板

将原照片适配为 3:2 横向分区。仅在指定的背景扩展蒙版区域生成内容。
保持原图主体区域受保护，不重绘脸部、身体、服装、重要物体或其他原有主体。
保持身份、面部特征、身体比例、姿势、表情、服装、物体和空间关系不变。
延续原环境、透视、摄影质感、自然光线、阴影、氛围和原色调。
仅延展天空、地面、墙壁或环境；结果应无缝且摄影写实。
不新增人物或重要物体，不美化或人工风格化主体。
