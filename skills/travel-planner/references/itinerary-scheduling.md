# 时间排程与可执行性

优先级：安全和入境 → 航班铁路硬截止 → 已订不可改项目 → 双方核心体验 → 其他偏好 → 可选项。逐日检查星期、各级假日、学校假期、大型活动、场馆/餐厅/交通/一日团是否运行；同建筑常设展、特展、塔楼、礼拜与游客窗口可能不同；免费日仍可能需预约及排队。

每段衔接按「前项结束＋离场取物＋步行到站/候车＋乘车换乘＋出口步行＋寄存/换票/安检＋缓冲」核算，必须早于下一项要求到场时间。完整保留参观时长，不混淆最后入场、售票截止、清场和关门；站到站时间不等于门到门。一般市内硬预约额外预留约 15–30 分钟，大型活动/拥堵/跨城交通更多，具体以运营方要求为准。机场按航司、机场、行李、边检及路况倒推，柜台截止不是目标抵达时间；长途抵达日不安排依赖最乐观交通的不可退活动。

初始节奏每天 1–2 个高耗能核心体验，搭配同区轻活动和约 45–90 分钟休息/自由时间；长馆日补水用餐，晚间演出后不默认次日早起。估算步行、爬楼、站立、行李负担。Tasting menu 按正常用餐时长，不依赖催菜；重餐后不强排夜市，检查连续重肉/酒庄重复；咖啡品鉴和正式下午茶独立留时。过敏/交叉接触必须由餐厅明确回复，不能以跳过某道菜视为安全。

跨城核对车站、上下车点、换乘、假期班次、行李寄取截止、酒店入住晚到、坡度台阶桥梁、末班与替代交通。修改一项预约时同步更新下游交通、餐饮、住宿、费用和休息。紧凑日给删减顺序及触发条件；雨天、疲劳、延误、抢票失败的备选也须核查目标日期开放和交通。
