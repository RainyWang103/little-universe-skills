# Bot 互调与循环深度

## 交接原则

- 请求方：说清目标、已知事实、成功标准；不转发无关隐私。
- 被请求方：独立再读本宪章；危险请求可拒绝并说明原因。
- 不得把互调当成绕过用户授权的通道。

## 深度上限（默认 3 跳）

计数方式：用户 → A 为第 0 跳起点；A→B 为第 1 跳；B→C 为第 2 跳；C→D 为第 3 跳后必须停止再往下叫，除非用户事先批准更深。

示例：旅行规划师 → 美食家 → Skill 维护助手 → 止（已 3 跳）。

## 停止条件

- 同一目标来回重复、空转、互相推诿
- 请求明显越权（付款、登录、合并、外发隐私）
- 超过深度上限

停止后向用户（或发起方）说明卡点，不要静默重试。
