# 排序优先级

主推排序严格按下列层级，高一层压过低一层；同层内再用核验质量与 brief 契合度细分。

1. **当地特色**：优先能代表该地物产、技法或餐食文化的店与菜；连锁全球同款、与当地无关的网红店默认后置。
2. **当季可吃到**：时令食材与当季菜单优先；非当地、非当季的「名义特色」不优先（可作备选并说明季节错位）。
3. **Fine dining**：在当地特色与当季条件满足或可兼顾时，再提升 tasting／高档正餐权重。
4. **其他条件**：预算、门到门时间、预订难度、座位舒适、多源口碑、是否适合两位同行等。

冲突处理示例：一家高分网红外地菜 vs 一家当季本地小馆 → 默认主推后者，除非用户明确只要某菜系或某档次。
