# 制作流程与验收

## 默认输出

一张独立的高端编辑海报，1536 × 2048 像素，PNG，无文字。
整体严格 3:4 竖版；上下两部分各占高度 50%，无间隙或外框。
每个分区实际为 3:2 横向画幅，默认各为 1536 × 1024 像素。
两个分区像同一本艺术出版物的封面，色彩与气质连贯。

## 工具要求

运行需要能读取用户图片、根据参考图生成插图的图像工具，以及 Python 3.9+ / Pillow。
背景扩展需要支持蒙版或保护原像素的编辑能力。工具不可用时如实说明，不声称已生成。
宿主的入口注册和工具绑定由宿主处理，本目录本身不会自动注册入口。
使用宿主规定的图像生成工具；确定性拼接使用附带脚本。

## 执行流程

### 1. 分析照片

先查看原图，识别主体数量、身份特征、轮廓、比例、姿势或手势、重要物体、空间关系与核心叙事。
确定不可裁切内容，提取最多四种代表性颜色。无需向用户输出长篇分析。

### 2. 准备上半部

优先直接使用原照片像素。保留主体、身份、面部、身体比例、姿势、表情、服装、物体与空间关系。
保留摄影写实质感、自然光线、阴影、氛围与原色调；仅做细微编辑色彩校正。
禁止拉伸、扭曲、重塑、替换主体，以及过度磨皮、夸张调色和人工风格化。

按顺序适配 3:2 分区：
1. 若不会丢失重要主体或叙事信息，等比缩放并安全裁切。
2. 否则仅扩展天空、地面、墙壁或环境背景。原图区域保持受保护，扩展必须无缝且摄影写实。
3. 若无法可靠扩展，保留原图比例，使用与下半部协调的暖纸色留边。无需追问，交付时说明。

不要要求模型重新生成整张照片来保持身份。背景扩展若有主体变化，恢复原主体像素后再使用。

### 3. 生成下半部

读取 [插图与背景提示词](image-prompt.md)，结合分析结果填写模板，并将原照片传给图像工具作为参考。
只生成下半部 3:2 插图分区，不让模型生成整张海报。

保留最易辨识的主体、基本轮廓与比例、关键姿势、重要物体、核心叙事关系。
高度简化，去掉辨识所不需要的细节。

使用细腻且略带瑕疵的手绘线条、少量丙烯风格平面色块、粗糙暖米白纸、
可见而克制的手工笔触和稍不规则的有机边缘。避免光滑矢量、3D、复杂阴影和过度做旧。

插图小巧居中，四周大量留白。将“占下半部 10–20% 空间”操作化为：
主要插图组合的紧凑外接框面积约占分区面积的 10–20%。纸张颗粒和零星环境线条不计入。
仅用少数线条或小色块暗示环境。

从照片提取最多四种主要插图颜色，克制、精致、和谐。纸张底色不计入；纹理变化不得形成新主色。

### 4. 排版

默认无文字。用户主动提供文案时可添加少量简单排版，最多两个字号层级，放在下半部留白中。
使用可靠字体与排版工具保证文案准确，不遮挡主体，不编造标题、品牌、署名或日期。

### 5. 合成与检查

将两个完成的 3:2 分区交给 scripts/compose_poster.py：

```bash
python scripts/compose_poster.py --photo photo-panel.png --illustration illustration-panel.png --output hand-drawn-poster.png
```

若上半使用原图留边策略，传入原图并添加 `--photo-fit contain`。
工具只等比缩放，不静默裁切或拉伸。比例不合格时修复相应分区后再合成。
不要对合成后的整张海报再次生成式重绘。

验收：
- 脚本检查画布为 3:4、分界在 50%、分区尺寸相等。
- 对照原图检查主体身份、比例、姿势、物体、空间关系和真实感。
- 目视检查插图立即可辨识、外接框约 10–20%、主要颜色不超过四种、留白与质感符合要求。
- 检查没有意外文字、水印或新增主体。

身份、颜色和插图面积检查是视觉评估，不宣称由脚本精确验证。
不合格时仅修正对应分区，再重新合成。

## 交付

展示最终海报，提供可下载 PNG。简短说明尺寸及是否有文字。
采用纸色留边时说明适配方式。不得将未生成的图片描述为完成品。
