# GPT 手绘海报流程与验收

## 目标与参考

目标为 3:4 竖版、1536×2048 PNG，上半真实照片、下半暖纸手绘，各占 50%。默认无文字；下半主体小巧居中，约占下半区 10–20%，最多四种照片主色。使用 [图像提示词](image-prompt.md) 的插图风格与保真约束。

## 1. 读图

先查看用户上传图片；确认主体、姿势、重要物体、空间关系和不可裁切内容。明确是创作请求且图片可读后直接执行。目标不明或缺图时才询问。

## 2. 按宿主能力选择制作方式

默认使用当前宿主提供的图像生成／编辑工具。把原照片作为参考，要求上半保留摄影真实感、下半采用纸本插图并严格描述两区布局。使用实际可用的参考图路径或会话图片参数，不编造参数或本地输出文件。

若宿主要求图像编辑必须走图像工具，不改用 Python 规避该约束。生成结果不能保证原照片像素逐点不变或尺寸、50% 分界完全精确；未取得本地文件检查时，明确这只是视觉验收，不声称像素级保真或精确尺寸。

仅当用户明确要求代码／Python 拼接，或宿主规则明确允许确定性合成时，走精确分支：只生成 3:2 下半插图，再用本包 scripts/compose_poster.py 与原照片合成；先核实 Pillow 可用。上半优先原像素，不能安全裁切时等比纸色留边；不能保护原图区域时不做生成式扩图。不得为了访问图片而绕过工具或下载限制；无法取得允许使用的本地图片时说明缺口。

```bash
python scripts/compose_poster.py --photo photo.png --illustration illustration-panel.png --photo-fit contain --output hand-drawn-poster.png
```

## 3. 验收与交付

对照原图目视检查人物身份、身体比例、姿势、服装、重要物体、主色、插图留白、两区布局以及意外文字。发现明显变形或新增主体时修正对应问题。只有实际读取文件并检查像素尺寸及合成边界，才能报告精确尺寸和 50% 分界达标；视觉判断与脚本检查分开描述。

遵循宿主图像展示与自动保存规则。不要仅为展示而下载重传生成图；用户要求独立文件且已实际保存成功时再提供文件。照片和输出不得提交公开仓库。无法生成时说明阻塞点，不把提示词当作已完成海报。
